# Jogo da Memória Yu-Gi-Oh 🃏

Um jogo da memória simples feito com HTML, CSS e JavaScript, usando cartas do universo Yu-Gi-Oh.

## 🚀 Como jogar
- Abra o arquivo `index.html` no navegador.
- Clique nas cartas para revelar.
- Encontre os pares corretos para vencer.

## 📂 Estrutura do projeto
- `index.html` → página principal
- `style.css` → estilos do jogo
- `reset.css` → reset de estilos
- `script.js` → lógica do jogo
- `img/` → imagens das cartas

## 🛠️ Tecnologias usadas
- HTML5
- CSS3
- JavaScript
